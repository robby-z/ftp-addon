# Reolink FTPS Server

Secure explicit FTPS server for Reolink cameras, powered by vsftpd.

Open the built-in Home Assistant web UI to browse each configured user's recording tree, preview browser-supported videos and images, seek within recordings, or download the original file. The browser is read-only and available only through authenticated Home Assistant Ingress.

See the complete [App documentation](DOCS.md) for storage preparation, configuration, Reolink settings, and troubleshooting.
