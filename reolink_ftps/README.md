# Reolink FTPS Server

Secure explicit FTPS server for Reolink cameras, powered by vsftpd.

Open the built-in Home Assistant web UI for a newest-first table of all camera recordings. Filter, sort, preview, download, or explicitly delete recordings, or switch to the original per-user folder view. The interface is available only through authenticated Home Assistant Ingress.

See the complete [App documentation](DOCS.md) for storage preparation, configuration, Reolink settings, and troubleshooting.
